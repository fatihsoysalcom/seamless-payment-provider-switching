# Seamless Payment Provider Switching

This example demonstrates how to design a payment processing system that allows for seamless switching between different payment providers. It uses the Strategy pattern to abstract provider-specific logic, mitigating vendor lock-in and enabling flexible integration of new providers. The application can dynamically choose or switch providers based on criteria like cost or availability without altering its core business logic.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
